# Troubleshooting example

Track connectivity status using `onConnectionStateChange` and use `reconnect` to reinitiate the connection to the Hyperbeam virtual computer.

## Steps

- Run `npm start` to launch the demo.
- You should see the connection state logs. Use the "Reconnect" button to reconnect.
