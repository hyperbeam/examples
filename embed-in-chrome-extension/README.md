# Embed in Chrome Extension

Embed the Hyperbeam virtual computer in a CSP-enforced Manifest V3 Chrome Extension.

## Steps

- Run `npm start` to start the server.
- Load the `extension` folder as an unpacked extension in your browser.
- Click the "Hyperbeam in Extension" toolbar button to launch the demo.
