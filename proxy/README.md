# Hyperbeam Proxy example

You will need to purchase a proxy from a proxy provider, such as [Ping Proxies](https://pingproxies.com/) or [Proxy Cheap](https://app.proxy-cheap.com/r/X9CqGe).

## Steps

- In `server.js`, replace `proxyHost`, `username`, `password` with your proxy details.
- Run `npm start` to launch the demo.
- You should see the traffic in the browser be sent through the proxy server.
